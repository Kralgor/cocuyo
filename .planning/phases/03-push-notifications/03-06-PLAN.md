<objective>
Turn the placeholder Notify tab into a real point-of-use push notification opt-in flow covering D-01 saved-zone auto-subscribe, D-02 independent toggles default on, D-03 saved-zone token updates, D-04 explainer before OS permission, D-05 anonymous anon-key push_tokens registration, and D-11 Spanish-first factual no-ETA copy.
The app must request OS permission only after user action, obtain
an Expo push token, register it to Supabase with the saved zone and per-type
preferences, and let users independently toggle outage, restoration, and
neighbor-warning notifications.

Covers D-01 saved zone auto-subscribes on permission grant; D-02 independent
toggles for Sin luz, Volvio la luz, and Aviso de zona vecina default on after
opt-in; D-03 saved-zone changes update the token row with one active zone per
device; D-04 point-of-use explainer before OS permission; D-05 anonymous
anon-key `push_tokens` registration with no device_fingerprint or identity/GPS
data; and D-11 Spanish-first factual copy with no invented ETAs.

Decision text carried forward:
- D-01: Saved zone auto-subscribes on permission grant — the single zone already
  persisted in MMKV. No multi-zone follow list.
- D-02: The `notify` tab exposes per-type independent toggles: "Sin luz",
  "Volvio la luz", and "Aviso de zona vecina". Each can be turned on/off
  separately; all default ON after opt-in.
- D-03: When the user changes their saved zone, the subscription follows it
  (token row updated to the new zone). One active zone subscription per device.
- D-04: Permission is requested at point of use, NOT during onboarding. The
  `notify` tab shows an "Activar notificaciones" explainer screen FIRST —
  states why, what is stored (push token + zone, anonymous), and that no
  identity/location is attached — then triggers the OS permission dialog on
  user action.
- D-05: Token registration POSTs to the new `push_tokens` table using the
  SUPABASE_ANON_KEY only. No `device_fingerprint`. The row is anonymous: token,
  subscribed zone key, platform, per-type toggle prefs, timestamps. No
  user-identifying data.
- D-11: Notification copy is Spanish-first, factual, consistent with the app's
  honesty principle. No invented ETAs.
</objective>
