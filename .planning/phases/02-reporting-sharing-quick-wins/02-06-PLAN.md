## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Report tab → Supabase REST | anon-key INSERT of report payload |
| GPS sensor → screen | coordinates used to resolve zone + optional report metadata |
| app → WhatsApp | share text leaves via OS handler (post-report SharePrompt) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-13 | Tampering | rapid repeated report taps | mitigate | canEnqueue 30-min gate disables buttons + cooldown notice; in-flight disable prevents double-tap |
| T-02-14 | Information Disclosure | report payload | mitigate | device_fingerprint null (ADR-005); lat/lon optional; anon key only |
| T-02-15 | Repudiation | offline report lost | mitigate | MMKV queue persists across restarts; flush on connectivity + foreground (useReportQueue) |
| T-02-19 | Information Disclosure | post-report share text | accept | Only public zone status + public link; user-initiated CTA; no user identity |
</threat_model>
