## Spacing Scale

Declared values (multiples of 4, in density-independent pixels):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4dp | Icon-to-label gaps, status dot margins |
| sm | 8dp | Compact element spacing, badge padding |
| md | 16dp | Default horizontal screen padding, card internal padding |
| lg | 24dp | Section padding, hero block vertical padding |
| xl | 32dp | Major section breaks, zone picker section divider |
| 2xl | 48dp | Trust screen logo-to-content gap |
| 3xl | 64dp | Trust screen top safe-area offset |

Exceptions:
- Tab bar icons: 22dp size (Ionicons standard, matched in Pattern 3)
- Touch targets: minimum 44dp height on all tappable rows (iOS HIG / Android 48dp material guideline — use 48dp to satisfy both)
- Status dots in zone picker: 8dp diameter with 4dp margin-right
- Staleness banner: 40dp fixed height (non-dismissible, compact)
- Hero status block: 120dp height minimum to ensure sunlight readability

---

## Typography

All sizes in sp (scale-independent pixels — React Native default unit).

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Display | 48sp | 700 (bold) | 1.1 | Hero status text: "SIN LUZ", "CON LUZ", "INESTABLE" |
| Heading | 20sp | 700 (bold) | 1.2 | Screen titles, section headers in zone picker |
| Body | 16sp | 400 (regular) | 1.5 | Zone names, signal card labels, settings body text |
| Label | 13sp | 400 (regular) | 1.3 | Status dots label, tab bar labels, staleness banner text, signal bar values |

Weight classes: regular (400) and bold (700). Two weight classes — no in-between. Use 700 for all headings and display text; use 400 for body and label text.

Font family: `undefined` (system default) — SF Pro on iOS, Roboto on Android. Do not declare a custom fontFamily in Phase 1.

**Sunlight readability note:** Display text at 48sp bold is mandatory — not a suggestion. Smaller hero text fails in direct Venezuelan sun on low-brightness screens.

| no_data | inkFaint | SIN DATOS | NO DATA |

### 60/30/10 Split Declaration

- **60% dominant:** bg — all screen backgrounds, safe-area backgrounds, tab bar fill
- **30% secondary:** panel — all card surfaces, modal sheets, zone picker rows, settings surface
- **10% accent:** accent (#E8C840) — reserved for: active tab indicator dot/text, "Comenzar" button fill, GitHub link button, signal bar fill (filled portion)

Accent is NOT used for: inactive tab icons, body text, dividers, hero status blocks (those use ok/warn/danger), or background fills.

### Political Color Rule

No red/blue/yellow combinations that evoke Venezuelan political parties. The danger color (#B03020 / #D04030) is desaturated dark red — not flag red. The accent (#E8C840) is a firefly amber-yellow — not flag yellow.

## Screen-by-Screen Interaction Contract

### 1. Trust Onboarding Screen

**Route:** `onboarding.tsx` — guarded by `Stack.Protected` (appears when `hasSeenOnboarding === false`)
**Layout:** Full screen, centered column, safe-area padding top/bottom
**Scroll:** No scroll — all content fits within viewport
**Components:**
- Cocuyo logo: centered, 80dp wide, 32dp margin-bottom
- Subtitle: Body 16sp inkDim, centered
- Trust points: 4 rows, each with a checkmark icon (Ionicons `checkmark-circle`, 20dp, ok color) + 12dp gap + text column (heading 16sp ink bold, body 13sp inkDim)
- Separator: 24dp vertical space between trust points and buttons
- GitHub link: Pressable row, left-aligned icon (Ionicons `logo-github`, 18dp) + label, accent border bottom 1dp, no fill
- Spacer: 16dp
- "Comenzar" button: Full width, 48dp height, accent fill (#E8C840), ink text (not white — ink is readable on yellow), 16sp bold (700), 8dp border radius

**Interaction:**
- "Comenzar" tap → set MMKV `hasSeenOnboarding = true` → Stack.Protected redirects to zone-picker
- GitHub link tap → `Linking.openURL('https://github.com/username/cocuyo')` (opens browser)
- Back gesture: disabled (Stack.Protected manages this declaratively — no back from onboarding)

**State:** Stateless. No loading, no error states. Screen is static content.

---

### 2. Zone Picker Screen

**Route:** `zone-picker.tsx` — guarded by `Stack.Protected` (appears when `hasSeenOnboarding === true && !selectedZone`)
**Layout:** Full screen, safe-area insets
**Components:**
- Header: Screen title "Selecciona tu zona" (Heading 20sp, ink)
- Search bar: TextInput, 48dp height, 16dp horizontal margin, md (16dp) padding, panel background, 8dp radius, inkFaint placeholder
- SectionList: State-grouped zones. Section headers are uppercase state names (Label 13sp, inkDim, xl left padding). Zone rows are 48dp height, panel background, md horizontal padding.
- Zone row: Status dot (8dp circle, statusColor()) + 8dp gap + zone display_name (Body 16sp, ink)
- Section separator: line color, 1dp height

**Interaction:**
- Search input → filters SectionList by zone display_name (case-insensitive), removes empty sections
- Zone row tap → set MMKV `selectedZone = regionKey` → Stack.Protected redirects to (tabs)/index
- Back gesture: only available if user navigated here from Settings "Cambiar zona" (not first launch)

**States:**
- Status dots use live data from React Query cache if available; inkFaint dot if no data yet (first launch, loading)
- Empty search: show centered "Sin resultados para '{query}'" in inkDim, Body 16sp

---

### 3. Zone Detail / Home Screen

**Route:** `(tabs)/index.tsx`
**Layout:** ScrollView, safe-area top, tab bar at bottom
**Components (top to bottom):**

**A. Header row (sticky, 48dp height):**
- Left: Zone name (Heading 20sp, ink)
- Right: Gear icon (Ionicons `settings-outline`, 24dp, inkDim, accessibilityLabel: "Abrir ajustes" / "Open settings") — taps open Settings modal

**B. Staleness banner (D-13, STAT-03):**
- Shown when: `isOffline || isStale` (cache > 15 min)
- Height: 40dp, full width, no horizontal margin
- Background: warn color (amber/orange)
- Text: Label 13sp, ink (dark text on amber background), centered
- Format: "Última actualización hace {N} min — sin conexión"
- Non-dismissible — no X button, no tap action

**C. Hero status block (D-12, STAT-01):**
- Height: minimum 120dp, vertically centered content
- Background: statusColor() of current status (danger/ok/warn/inkFaint)
- Status label: Display 48sp bold, white text (use #FFFFFF always on colored hero, regardless of theme — contrast is guaranteed by color choice)
- Duration line (STAT-02): shown only when `outage?.started_at` exists
  - Format: "Hace {X} h {Y} min" — Body 16sp, rgba(255,255,255,0.80)
  - Uses `elapsed_minutes` from `outage` field in RegionEntry

**D. Signal breakdown cards:**
- 3 cards: Internet, Reportes, Satélite (horizontal scroll on small screens, or vertical stack — use vertical stack for clarity)
- Each card: panel background, md padding, 8dp radius, sm gap between elements
  - Label: Label 13sp, inkDim (signal name)
  - Bar: full width minus padding, 8dp height, 4dp radius, lineStrong track, accent fill proportional to signal value (0.0–1.0)
  - Value: Label 13sp, ink, right-aligned (e.g. "72%")
  - If signal is null: bar is empty (lineStrong only), value shows "—"

**E. Last updated row:**
- Bottom of scroll content
- Label 13sp, inkFaint, centered
- Format: "Actualizado hace {N} min"
- Not shown when staleness banner is visible (redundant)

**Interaction:**
- Pull-to-refresh: RefreshControl → trigger React Query refetch
- Gear icon: opens Settings modal
- No other interactions on home screen in Phase 1

**States:**
- Loading (first launch, no cache): skeleton shimmer on hero block (animated placeholder, panel color with shimmer overlay) + skeleton signal cards
- Error (first fetch failed, no cache): "Sin datos aún — conecta a internet para la primera carga" centered, inkDim, Body 16sp
- Loaded: full content as above
- Offline + stale: staleness banner + cached content below

## Skeleton / Loading States

Skeleton shimmer applies only to Zone Detail screen on first launch with no cache.

| Component | Skeleton shape |
|-----------|----------------|
| Hero status block | Rectangle 120dp height, full width, panel color, shimmer animation |
| Signal card | Rectangle 80dp height, ~30% screen width, panel color, shimmer |

Shimmer: animated opacity 0.5→1.0→0.5 loop, 1200ms duration, ease-in-out.
Zone picker status dots show inkFaint (static) while loading — no shimmer on picker.

## Theme Token Reference

Executor must implement `MobileTheme` interface with these exact token names. Both light and dark themes must declare all tokens.

```typescript
// mobile/constants/colors.ts
export interface MobileTheme {
  bg:          string;   // dominant surface (60%)
  panel:       string;   // secondary surface (30%)
  ink:         string;   // primary text
  inkDim:      string;   // secondary text
  inkFaint:    string;   // tertiary text / placeholders
  accent:      string;   // Cocuyo yellow — 10% usage
  ok:          string;   // power on / normal
  warn:        string;   // unstable / staleness
  danger:      string;   // no power
  line:        string;   // dividers
  lineStrong:  string;   // strong dividers, signal bar track
}
```

MMKV key for theme override: `'themeOverride'` — values: `'light' | 'dark' | null`
Default when no override: follow system preference. If system pref unavailable, use `'dark'` (OLED, Venezuela).
