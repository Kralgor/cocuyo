<decision_coverage>
- D-01: `FOOD_PRESETS` stays focused on basic groceries and common perishables,
  not restaurants or pantry management.
- D-02: Presets include dairy, meats, eggs, cooked leftovers, cooked rice or
  prepared staples, vegetables/fruits, and freezer/fridge container presets.
- D-03: Preset labels and caution copy are Spanish-first, with English optional
  through the existing i18n fallback pattern where useful.
- D-06: `foodTrackedItems` is persisted only in MMKV through storage helpers.
- D-12: Custom foods accept only `name`, `thresholdMinutes`, optional category,
  and optional warning lead. No complex inventory fields.
- D-13: Helpers include fast remove and reset operations for tracked foods.
- D-14: The implementation chooses a compact practical catalog; avoid expanding
  beyond the research suggested grocery set.
- D-17: Each preset has `warningLeadMinutes` below `thresholdMinutes` so warnings
  happen before the hard threshold.
</decision_coverage>

    Each preset must include Spanish `name`, `category`, `thresholdMinutes`,
    `warningLeadMinutes`, and concise `cautionText`. Keep thresholds conservative
    and understandable; do not imply temperature knowledge. Candidate examples:
    short fridge foods warn 30 to 60 minutes before threshold; freezer presets
    warn 2 to 4 hours before threshold.

    Add pure helpers:
    - `createTrackedFoodFromPreset(presetId, nowIso)` returns an enabled item
      with generated local ID, preset label, threshold, warning lead, and
      `createdAt`.
    - `validateCustomFood(input)` returns `{ ok: true }` or
      `{ ok: false, message: string }`. Reject blank names, thresholds below
      15 minutes, thresholds above 72 hours, and warning leads greater than or
      equal to threshold.
    - `createCustomTrackedFood(input, nowIso)` normalizes name whitespace and
      creates an enabled custom item.
    - `classifyFoodTimer(item, outageStartedAt, now)` returns `safe`,
      `warning`, or `expired` using elapsed minutes from the outage start.
    - `getFoodTimerProgress(item, outageStartedAt, now)` returns elapsed minutes,
      remaining minutes, percent clamped 0 to 100, and warning level.
